## 決策與陷阱
- **時序解耦**：worker 非 pre_tick，LLM 在 to_thread → tick 不被 15s LLM 拖慢。
- **AI issuer 用 COMMANDER（非 override）**：仍受 faction 檢查 → LLM 幻想命令他方單位會被 submit 權限擋（test 驗證）。
- **敵情首版 ground-truth HOSTILE**（感測 NoOp）；worker 只依賴 EnemyVisibility 協定，真偵測上線換 IntelService 即可。
- **gating**：ai_config 缺 / AI_OFF / 無 base_url → 不啟動（既有 session 安全）。
- **限制**：config 於 runner 起跑時讀一次；已在跑的 session 需重啟 runner 或新建 session 才生效（動態熱掛載列 O11.8）。
